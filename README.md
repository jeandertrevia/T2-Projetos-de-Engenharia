# Projetos de Engenharia de Dados

Repositório para submissão dos projetos finais da disciplina **Projetos de Engenharia de Dados**. Cada equipe deve enviar seu trabalho em uma pasta própria dentro de [`entregas/`](entregas/), por meio de um Pull Request.

## Comece por aqui

- [Como enviar o trabalho por Pull Request](COMO_ENVIAR.md)
- [Regras de avaliação](REGRAS_DE_AVALIACAO.md)
- [Estrutura de entregas e modelo por equipe](entregas/README.md)
- [Documento de referência da disciplina](doc/Projetos%20de%20Engenharia%20de%20Dados.pdf)

## Estrutura

```text
.
├── doc/
│   └── Projetos de Engenharia de Dados.pdf
└── entregas/
    ├── README.md
    ├── _modelo/
    │   ├── README.md
    │   ├── docs/
    │   │   └── arquitetura.md
    │   ├── src/
    │   └── tests/
    └── <nome-da-equipe>/
```

Cada pasta de equipe deve conter o projeto executável e sua documentação. Não inclua credenciais, arquivos `.env` reais ou dados cuja distribuição não esteja autorizada.
